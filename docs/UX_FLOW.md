# АТЛЕТИКА --- карта экранов и UX-логика

## 0. Главная

-   Показывает следующую тренировку.
-   Основная кнопка «НАЧАТЬ ТРЕНИРОВКУ» открывает следующий
    тренировочный день по логике программы.
-   Нижние разделы: «ИСТОРИЯ», «ПРОГРАММА», «НАСТРОЙКИ».
-   В карточке следующей тренировки не показывать лишние сведения вроде
    количества упражнений и длительности, если пользователь отдельно не
    попросит.

## 1. Программа

-   Две карточки: «ДНИ» и «УПРАЖНЕНИЯ».

## 2. Упражнения: список

-   Список существующих упражнений.
-   Действия: импортировать, экспортировать, добавить упражнение.
-   У каждой записи: редактировать (карандаш), удалить (корзина).
-   Удаление требует экрана/диалога подтверждения.
-   Импорт и экспорт предпочтительно представлены иконками, если подписи
    остаются понятными.

## 3. Упражнение: создать/редактировать

-   Название.
-   Описание.
-   Ссылка на видео.
-   Пока не добавлять параметры веса.

## 4. Дни: список

-   Список тренировочных дней.
-   Можно создавать, переименовывать, редактировать и удалять дни.
-   Пример placeholder названия: «Например, День 1».

## 5. Тренировочный день: настройка

-   Название дня, например «Верх тела».
-   Список упражнений, выбираемых из библиотеки.
-   Настройка числа подходов и повторений для каждого подхода.
-   Отдых задаётся для каждого подхода отдельно, включая последний.
-   Можно менять порядок упражнений перетаскиванием.
-   Можно добавлять обычные упражнения и серии.

## 6. Серии

-   Серия объединяет несколько упражнений, которые выполняются
    циклически.
-   Для каждого упражнения внутри серии задаются повторения.
-   Задаётся количество циклов серии.
-   Пример: подтягивания 5 повторений, брусья 6 повторений, отжимания 10
    повторений, повторить цикл 5 раз.
-   UX серии ещё требует проработки. Кнопка «Добавить серию» должна быть
    доступна внизу экрана дня и визуально соответствовать «Добавить
    упражнение».

## 7. Настройка упражнения в тренировочном дне

-   Редактирование параметров конкретного упражнения внутри конкретного
    дня.
-   Не включать веса.
-   Не показывать информационную плашку с очевидными инструкциями.
-   Главная иллюстрация: упоры для отжиманий в согласованной стилистике.
-   Подходы, повторения и отдых должны редактироваться явно и понятно.

## 8. Тренировка

-   Основной сценарий запускается с главной.
-   Приложение определяет, какой день программы должен быть следующим, и
    открывает тренировку этого дня.
-   Экран активной тренировки должен показывать текущее
    упражнение/подход и таймер отдыха по согласованной логике.
-   Детали активной тренировки ещё предстоит спроектировать.

## 9. История

-   Хронологическая история завершённых тренировочных дней.
-   Экспорт/копирование истории.

## 10. Настройки

Возможные кандидаты для будущего обсуждения: - выбор поведения перехода
к следующему дню; - звук/вибрация таймера отдыха; - формат отображения
времени; - экспорт/резервное копирование данных; - сброс/очистка истории
с подтверждением. Не считать этот список окончательно утверждённым.

## Открытые вопросы

-   Как именно вычислять следующий тренировочный день, если пользователь
    пропускает тренировку или редактирует программу.
-   Какие действия доступны для серии целиком и для отдельных упражнений
    внутри серии.
-   Как выглядит активная тренировка, таймер отдыха и завершение
    тренировки.
-   Как импортируются/экспортируются упражнения и история: формат и
    целевые сценарии.

# ATLETIKA docs

Start with **`APP_OVERVIEW.md`**: the app as it is today (screens, rules, data, visual system, tests). Working rules for the code are in `../CLAUDE.md`.

- `ATLETIKA_PRODUCT_SPEC.md`: the original English product, UX and UI brief.
- `DECISIONS.md`: decisions made after the spec, newest first. It overrides the spec where they conflict, and lists the provisional choices.
- `TYPOGRAPHY.md`: fonts and type hierarchy.
- `DEVICE_CHECKLIST.md`: checks to do on a real iPhone and Android phone.
- `assets/reference_screens/`: the original screen references; `assets/supplied_YYYY-MM-DD/`: artwork and references supplied later; `assets/approved_components_overview.jpg`: the approved component samples.
- `mockups/`: PNG mockups made during design discussions.
- `DESIGN_SYSTEM.md`, `UX_FLOW.md`, `HANDOFF.md`: notes from the mockup phase, before any code. Kept for history; where they differ from `APP_OVERVIEW.md` or `DECISIONS.md` (for example import/export on the library screen), those win.

The application UI must be in Russian, and every UI font must support Cyrillic. Do not invent behavior for items marked OPEN / NOT DECIDED.

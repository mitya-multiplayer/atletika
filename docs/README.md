# ATLETIKA Claude Code Package

Start with **`ATLETIKA_PRODUCT_SPEC.md`**. It is the consolidated English-language product, UX, and UI implementation brief.

- `DECISIONS.md` records decisions made after the spec. It overrides the spec where they conflict.
- `TYPOGRAPHY.md` defines the fonts and type hierarchy.
- `assets/reference_screens/` contains the original supplied screen references.
- `assets/approved_components_overview.jpg` shows the currently approved component samples.
- `DESIGN_SYSTEM.md`, `UX_FLOW.md`, and `HANDOFF.md` preserve the earlier project context documents.

The application UI must be in Russian, and every UI font must support Cyrillic. The detailed specification identifies confirmed decisions separately from unresolved product questions. Do not invent behavior for items marked OPEN / NOT DECIDED.
